🔖 Luna Styles — Whatnot Sync Bookmarklet

One click on your Whatnot shop page → your website updates automatically in ~30 seconds.

Step 1 — Drag this to your bookmarks bar:

🌙 Whatnot Sync

Make sure your bookmarks bar is visible (Ctrl+Shift+B in Chrome/Edge).

Step 2 — GitHub token (skip if already set up for Etsy Sync):

  1. Go to github.com/settings/personal-access-tokens/new
  2. Name it Luna Styles Sync
  3. Under Repository access, choose Only select repositories and pick Lunastyles-
  4. Under Permissions → Repository permissions, set Contents to Read and write (leave everything else as No access)
  5. Click Generate token and copy it

A token scoped this way can only write to this one repo — safer than a classic token with full repo access. It's stored only in your browser's localStorage — never sent anywhere except GitHub.

Step 3 — Use it:

  1. Log in to Whatnot as lunastyles
  2. Go to whatnot.com/user/lunastyles/shop
  3. Click Whatnot Sync in your bookmarks bar
  4. First time: paste your GitHub token when prompted
  5. Watch the toast — it will say ✓ when done
  6. Site updates in ~30 seconds

⚠️ You must be logged in to Whatnot as lunastyles to see your listings.
